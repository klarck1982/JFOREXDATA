# دليل نشر الأرشيف على الإنترنت (بالعربي)

الحزمة الجاهزة: مجلد `site/` (كتاب HTML ذاتي الاكتفاء + ملفات خام) و`ttfm-archive.zip` نفسه.
اختر طريقة واحدة حسب حاجتك للخصوصية:

## الطريقة أ — Netlify Drop (الأسرع، بدون حساب مدفوع، رابط غير مفهرس)
1. افتح https://app.netlify.com/drop
2. اسحب مجلد `site/` (أو ملف zip مباشرة) إلى نافذة المتصفح.
3. تحصل فوراً على رابط مثل `https://xxxx.netlify.app` — الكتاب والصور والفيديو والكود كلها تعمل.
4. مجاناً؛ الرابط يبقى ما لم تحذفه؛ يمكن ربط دومين لاحقاً أو حذف الموقع بضغطة.
ملاحظة: الموقع «عام لمن يعرف الرابط» وغير مفهرس في محركات البحث افتراضياً.

## الطريقة ب — GitHub Pages (الأدوم، مع تاريخ نسخ versioned)
1. أنشئ مستودعاً جديداً على github.com (عام أو خاص حسب خطتك).
2. ارفع محتوى مجلد `site/` إلى جذر المستودع (سحب وإفلات في واجهة الموقع تكفي).
3. من Settings → Pages → Branch: main / root → Save.
4. خلال دقيقة يصبح الكتاب على `https://username.github.io/repo/`.
ميزة إضافية: كل تحديث للنقاش = commit جديد محفوظ للأبد.

## الطريقة ج — GitHub Gist سري (كود + نصوص فقط، بدون صور)
1. صدّر توكن شخصي من GitHub (Settings → Developer settings → Tokens) بصلاحيات gist.
2. شغّل: `GITHUB_TOKEN=xxx bash publish_gist.sh`
3. Script ينشئ gist سرياً (unlisted) بكل ملفات .java و.md — رابط واحد تشاركه مع صديقك.
الصور والفيديو لا تناسب gist؛ فهي للطريقتين أ/ب.

## الطريقة د — Google Drive / Dropbox (خاص تماماً)
1. ارفع `ttfm-archive.zip` إلى مجلد Drive.
2. مشاركة → «أي شخص لديه الرابط» أو أشخاص محددين بالبريد.
3. الطرف الآخر ينزل zip ويفتح `site/index.html` في متصفحه — كل شيء يعمل offline.

## التحقق من السلامة (لا فقدان)
- `MANIFEST.txt` داخل site/ يحوي بصمات SHA-256 لكل ملف مصدر.
- بعد النشر/التنزيل شغّل: `sha256sum -c MANIFEST.txt` (من داخل مجلد الأصول) وتأكد أن كل السطور OK.

## ماذا يحوي الكتاب index.html تحديداً؟
سجل النقاش الكامل (§1-11) + جداول القرارات والأقفال + الكود الكامل مضمناً (TTFMCore.java والاختبارات) + كل الصور الرسمية وصور المستخدم مع ملاحظات الفحص البكسلي + أدلة SVG + دليل الإعدادات + خلاصات المصادر الخارجية بروابطها + خطة Essence الحالية + روابط تنزيل PDF والفيديو والكود الخام.
