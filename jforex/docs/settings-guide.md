# دليل إعدادات مؤشر TTFMCore — مراجعة كاملة مبسطة
> كل خيار كما يظهر في نافذة إعدادات JForex (إنجليزي) + شرحه بالعربي + قيمته الافتراضية الحالية.
> الافتراضي = ما يعمل عندك الآن دون تغيير. أي تعديل يُطبق فوراً عند OK.

---

## 1) الطبقات — Layers (15 خياراً: 5 لكل طبقة)
الطبقة = شموع إطار أعلى تُبنى من بارّات شارتك وتُرسم كأعمدة على يمين الشاشة.

| الخيار | الافتراضي | الشرح المبسط |
|---|---|---|
| `[Layer 1] Enable` | **Yes** | تشغيل الطبقة الأولى (المقصودة: 4H). |
| `[Layer 1] Timeframe` | **4 Hours** | إطار الطبقة الأولى. |
| `[Layer 1] Candles` | **6** | عدد شموع 4H المعروضة في السلّم يميناً. |
| `[Layer 1] Position` | **Right** | مكان السلّم: يسار/تداخل/يمين الشاشة. |
| `[Layer 1] Offset` | **10** | إزاحة السلّم عن حافة الشاشة (لتباعد الطبقات). |
| `[Layer 2] Enable` | **Yes** | تشغيل الطبقة الثانية (اليومي). |
| `[Layer 2] Timeframe` | **Daily** | إطار الطبقة الثانية. |
| `[Layer 2] Candles` | **3** | عدد شموع اليومي المعروضة. |
| `[Layer 2] Position` | **Right** | مكان سلّم اليومي. |
| `[Layer 2] Offset` | **5** | إزاحته. |
| `[Layer 3] Enable` | **No** | الطبقة الثالثة معطّلة بالاتفاق (7H محفوظة للتجريب). |
| `[Layer 3] Timeframe` | 7 Hours | إطارها لو فعّلتها. |
| `[Layer 3] Candles` | 3 | عدد شموعها. |
| `[Layer 3] Position` | Right | مكانها. |
| `[Layer 3] Offset` | 5 | إزاحتها. |

## 2) العرض العام — Display
| الخيار | الافتراضي | الشرح المبسط |
|---|---|---|
| `[Display] Show Timer` | **No** | عدّاد تنازلي ملوّن فوق أعلى شمعة بكل سلّم (فعّلته يدوياً سابقاً؟ إن ظهر عندك Yes فهو تعديلك). |
| `[Display] Candle Body Scale (%)` | **100** | سماكة أجسام شموع السلّم (50–200%). |
| `[Display] Color Scheme` | **Green + Black** | ألوان أجسام السلّم: أخضر/أسود أو أبيض/أسود. |
| `[Display] Show Closures` | **Yes** | أعمدة C1‑C6 على توقيت الشارت: شريط رمادي متناوب + خط منقّط عند فتح كل شمعة مرجعية + التسمية `C1 (09:00-13:00)`. |
| `[Display] Closure Color` | **Black** | لون الخط العمودي المنقّط. |
| `[Display] Closure Style` | **Dotted** | نمطه (Solid/Dashed/Dotted). |
| `[Display] Closure Width` | **1** | سماكته (1–5). |

## 6) محرك CISD — المحرك الأساسي (مستقل عن الإضافات)
| الخيار | الافتراضي | الشرح المبسط |
|---|---|---|
| `[CISD] Detection` | **Yes** |_MASTER_ المحرك: كشف انعدام التسليم العكسي (CISD) على الطبقة المرجعية + خط الإشارة + الوقف المحمي. |
| `[CISD] Min Wave Length` | **Medium (min 2)** | حساسية طول موجة الدفع قبل احتساب CISD (الأعلى = إشارات أقل وأنقى). |
| `[CISD] Ignore Inside Bars` | **Yes** | تجاهل الشموع الداخلية عند تتبع الموجة (أنظف). |
| `[IC] Skip Late IC-CISD` | **No** | تجاهل إشارات الـ IC المتأخرة داخل شمعة الـ HTF (فلتر جودة — مرشح للتفعيل بالخطوة ٤). |
| `[State] Color States (gray/orange/red)` | **Yes** | تلوين حالة الإشارة: رمادي صالح / برتقالي شدّد / أحمر فشل + لافتات الحالة. (يتبع مفتاح AddOns أدناه.) |

## 7) الإضافات والأهداف — AddOns & Projections

## وصفات سريعة
- **مطابقة TradingView كاملة (أي فصل):** `Chart Timezone = New York` + `HTF Session Anchor = NY 18:00 Auto` (مؤشرات/آجل) أو `NY 17:00 Auto` (فوركس/CFD).
- **أهدأ شاشة ممكنة:** `[AddOns] Targets+States Master = No` (يبقى المحرك: خطوط CISD + الوقف) + `[Struct] Show FVG Zones = No`.
- **شاشة النظرية الكاملة:** فعّل `Show Bias Label` + `Semantic C1-C4 Labels` + `Show Liquidity Sweep` + `Show OB/Breaker`.
- **لوحتي لا تشبه ساعتي:** `[Panel] Time Line` اختر الوضع المناسب (افتراضياً ساعتك الحيّة).
- **سلّم رسمي TV:** `[Proj] Ladder Anchor = Manip-Candle EQ (official TV)`.

*ملاحظة: خيارات «محفوظة مطفأة» موجودة بالكود ومتفق أن تبقى OFF حتى تطلب تفعيلها — قاعدة العمل المعتمدة.*
