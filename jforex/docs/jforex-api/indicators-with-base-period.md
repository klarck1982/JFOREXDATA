# Indicators with base period

                    Base period is used for indicators which have unstable period of calculations.

Indicators listed below are marked as unstable-period indicators in code:

- ADX - Average Directional Movement Index

- ADXR - Average Directional Movement Index Rating

- ALLIGATOR - Alligator

- APO - APO

- ATR - Average True Range

- AWESOME - Awesome Oscillator

- AWESOME2 - Awesome Oscillator

- BBANDS - Bollinger Bands

- BBANDSFIB - Bollinger Bands - Fibonacci Ratios

- BBANDWIDTH - Bollinger Bandwidth

- BEARP - Bear Power

- BULLP - Bull Power

- BUTTERWORTH - Butterworth Filter

- CAMPIVOT - Camarilla Pivots

- CDLMORNINGDOJISTAR - Morning Doji Star

- CDMI - Chande's Dynamic Momentum Index

- CHAIKIN_VOLATILITY - Chaikin's Volatility

- CHOP_INDEX - Choppiness Index

- CMO - Chande Momentum Oscillator

- COG - Center of gravity

- CQS - Chande's QStick

- CSS - Currency Slope Strength

- DARVAS_BOX - Darvas Box

- DEMA - Double Exponential Moving Average

- DISP_INDEX - Disparity Index

- DMI - Average Directional Movement Index

- DX - Directional Movement Index

- EF_TRANSFORM - Ehlers Fisher Transform

- ELLOSC - Elliott Oscillator

- EMA - Exponential Moving Average

- EMAENVELOPE - EMA Envelope

- FIBPIVOT - Fibonacci Pivot

- FORCEI - Force Index

- FRACTALLINES - Fractal Lines Indicator

- GANN_HILO - Gann HiLo Activator

- GANN_SWING - Gann Swing Oscillator

- GANN_TREND - Gann Trend Oscillator

- GATOR - Gator Oscillator

- HEIKINASHI - Heikin Ashi

- HEIKINASHILINES - Heikin Ashi Lines

- HEIKINASHISINGLE - Heikin Ashi with a single candle output

- HEIKINASHISMLINES - Heikin Ashi Smoothed Lines

- HEIKINASHISMOOTH - Heikin Ashi with smoothed indicator

- HT_DCPERIOD - Hilbert Transform - Dominant Cycle Period

- HT_DCPHASE - Hilbert Transform - Dominant Cycle Phase

- HT_PHASOR - Hilbert Transform - Phasor Components

- HT_SINE - Hilbert Transform - SineWave

- HT_TRENDLINE - Hilbert Transform - Instantaneous Trendline

- HT_TRENDMODE - Hilbert Transform - Trend vs Cycle Mode

- ICHIMOKU - Ichimoku

- ICHIMOKUVF - Ichimoku VF

- INERTIA - Inertia

- KAIRI - Kairi

- KAMA - Kaufman Adaptive Moving Average

- KBANDS - Keltner Bands (Based on ATR)

- KDJ -  Random Index

- KURTOSIS - Kurtosis

- LAGACS1 - Laguerre-ACS1

- LRSI - Ehlers Laguerre Relative Strength Index

- LWMA - Linear Weighted Moving Average (LWMA)

- MA - Moving average

- MACD - Moving Average Convergence/Divergence

- MACDEXT - MACD with controllable MA type

- MACDFIX - Moving Average Convergence/Divergence Fix 12/26

- MAMA - MESA Adaptive Moving Average

- MAMA2 - MESA Adaptive Moving Average

- MASS_INDEX - Mass Index

- MAVP - Moving average with variable period

- MCCLHIST - McClellan Histogram

- MCCLOSC - McClellan Oscillator

- MCCLSUM - McClellan Summation Index

- MFI - Money Flow Index

- MINUS_DI - Minus Directional Indicator

- MINUS_DM - Minus Directional Movement

- NATR - Normalized Average True Range

- OBV - On Balance Volume

- OSMA - Moving Average of Oscillator

- PIVOT - Pivot

- PLUS_DI - Plus Directional Indicator

- PLUS_DM - Plus Directional Movement

- PPO - PPO

- RAINBOW - Rainbow Charts

- RAINBOW_OSC - Rainbow Oscillator

- RMI - Relative Momentum Index

- RMTA - Recursive Moving Trend Average

- RSI - Relative Strength Index

- S&R - Support and Resistance
